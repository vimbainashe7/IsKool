# API Conventions

- All REST APIs live under `/api/v1`.
- Controllers parse and validate requests, then call services.
- Controllers must not access Prisma, raw SQL, storage SDKs, LLM providers, or queue clients directly.
- Services own transaction boundaries and business orchestration.
- Repositories own persistence details.
- Errors use the standard error envelope in `docs/contracts/ERROR_CONTRACT.md`.
- Swagger/OpenAPI is generated by each API service.
- Request IDs are accepted from `x-request-id` or generated server-side.
