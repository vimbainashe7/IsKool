# Browser evidence

`teacher-{width}.png`, `student-{width}.png` and `admin-{width}.png` are Playwright screenshots of explicit preview dashboards at 360, 390, 768, 1024, 1280 and 1440 pixels. They are regenerated by the responsive workflow test. `teacher-desktop.png` is the earlier manual agent-browser inspection before dashboard list limits were added; prefer the numbered viewport files for final evidence.

Screenshots contain sample records, not production data. Browser traces and reports are generated in ignored `test-results/` and `playwright-report/`. Read ../QA_REPORT.md for actual outcomes, coverage and production limits.
