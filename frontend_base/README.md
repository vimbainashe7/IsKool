# IsKool frontend

The shared Next.js frontend lives here; backend commands run one directory above.
Use the [canonical root developer guide](../README.md) for Windows setup, independent Node 22/24 toolchains, live API configuration, startup, developer quick-fill and acceptance commands.

Authentication uses IsKool APIs and HttpOnly sessions. School membership is verified by the backend. Academic projection APIs remain future domain work and the live UI reports empty states rather than sample records.

Frontend implementation details: [architecture](docs/frontend/ARCHITECTURE.md), [UI primitives](docs/frontend/UI_PRIMITIVES.md), [route capabilities](docs/frontend/ROUTE_CAPABILITY_MATRIX.md), and [backend contracts](docs/frontend/BACKEND_CONTRACTS.md). Historical evidence and preview documentation are not proof of live backend acceptance.
